Pilih ZIP hasil Simpan Proyek dari ADM AR Studio. Mode ini untuk pratinjau lokal; untuk membuat tautan publik, unggah isi proyek ke GitHub.

Cara menerbitkan proyek

  1. Di ADM AR Studio, impor file targets.mind yang cocok dengan marker.
  2. Simpan proyek lengkap sebagai ZIP.
  3. Ekstrak ZIP dan unggah project.json, folder assets, dan targets.mind ke satu folder proyek di GitHub.
  4. Untuk tautan per folder, buka ?folder=fania atau ?folder=varen. Isi folder harus berisi project.json, targets.mind, dan folder assets.
  5. Bagikan tautan tersebut. Pengguna perlu mengizinkan kamera dan memindai marker yang benar.

Catatan: gambar marker saja tidak cukup untuk tracking. File targets.mind harus dibuat dengan MindAR Image Target Compiler untuk gambar marker yang digunakan.
